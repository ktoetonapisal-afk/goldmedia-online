Our product: Keyword Intelligence Pipeline

We build a local, reproducible keyword research pipeline for Shopify stores (US market, supplements niche). The tool consolidates keyword data from multiple third-party SEO services and validates them against the ground truth: the Google Keyword Planner API.

1. Collect

Keyword sets from third-party SEO research services (answers, suggestions, questions, ad history) into a local PostgreSQL database.

2. Validate

KeywordPlanIdeaService.generate_keyword_ideas fetches authoritative monthly search volume, competition level and top-of-page bid estimates for the semantic core.

3. Reconcile

Exact-match ratios and overlap scores rank sources against Google data; outliers are discarded.

4. Produce

Enriched semantic core feeds product pages (PDP) and informational content; clusters drive publishing roadmap.

How we use the Google Ads API

  • Read-only scope: only GenerateKeywordIdeas. No campaign creation, no account or campaign management, no conversion tracking.
  • Targeting: en-US, Google Search network, US geo-territory; up to 20 seed keywords per request (per API limits).
  • Internal use only: sole proprietor workflow. No public users.
  • No personal data is stored — only aggregated search metrics.

Validation against third-party services

Third-party tools report different metrics for the same keywords. We compare Google Keyword Planner values (exact-match share, median ratio) with each reseller feed and quantify: coverage, uniqueness, meta-field richness. This gives the store a trusted semantic core instead of a fragile reseller consensus.
